# Agent Instructions

- Treat each lesson directory as a separate Java exercise; keep changes scoped to the lesson being worked on.
- Preserve the assignment prompts and requirements in `Main.java`, and do not remove instructional comments or supplied reference images.
- Follow the existing beginner-friendly Java style and reuse the local `Input` helper when appropriate. Avoid adding dependencies or introducing build tooling for a single exercise.
- Compile and run from the target lesson directory so its files and relative paths resolve correctly. For example: `javac *.java` followed by `java Main`.
- Keep generated `.class` files and other build artifacts out of source changes.
